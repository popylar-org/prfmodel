prfmodel.impulse.TransientImpulse
=================================

.. py:class:: prfmodel.impulse.TransientImpulse(duration: float = 32.0, offset: float = 0.0, resolution: float = 1.0, norm: str | None = None, default_parameters: dict[str, float] | None = None, shape: float = 9.0, inhibitory_shape: float = 10.0, inhibitory_time_constant_ratio: float = 1.33)



   Transient temporal channel impulse model.

   Predicts the on-transient impulse response :math:`h_2` of the compressive spatiotemporal (CST) model [1]_, a
   biphasic response formed as the difference between an excitatory and a slower inhibitory gamma density.
   The model has one parameter: `time_to_peak` is the peak time (in seconds) of the excitatory component.

   The off-transient :math:`h_3` is identical with the opposite sign, so it is obtained by negating this response
   rather than by a separate class.

   :param duration: The duration of the impulse response (in seconds).
   :type duration: float, default=32.0
   :param offset: The offset of the impulse response (in seconds).
   :type offset: float, default=0.0
   :param resolution: The time resolution of the impulse response (in seconds), that is the number of points per second at which
                      the impulse response function is evaluated.
   :type resolution: float, default=1.0
   :param norm: The normalization of the response. Can be `"sum"`, `"mean"`, `"max"`, `"norm"`, or `None` (default).
                If `None`, no normalization is performed. Leave this at `None`: the two components each integrate to one, so
                a biphasic response sums to approximately zero and `norm="sum"` divides by that near-zero value.
   :type norm: str, optional, default=None
   :param default_parameters: Dictionary with scalar default parameter values. Dictionary keys must be valid parameter names.
                              Default values can be overriden in the :meth:`__call__` method.
   :type default_parameters: dict of float, optional
   :param shape: Shape of the excitatory gamma distribution (:math:`m` in the reference). Fixed at 9 in [1]_.
   :type shape: float, default=9.0
   :param inhibitory_shape: Shape of the inhibitory gamma distribution. Fixed at 10 in [1]_.
   :type inhibitory_shape: float, default=10.0
   :param inhibitory_time_constant_ratio: Scale of the inhibitory gamma distribution relative to the excitatory one (:math:`\kappa` in the
                                          reference). Fixed at 1.33 in [1]_. Values above one make the inhibitory component slower, which is what
                                          produces the biphasic shape.
   :type inhibitory_time_constant_ratio: float, default=1.33

   .. seealso::

      :py:obj:`SustainedImpulse`
          The sustained temporal channel of the same model.

   .. rubric:: Notes

   The excitatory component is identical to :class:`SustainedImpulse`, so it peaks at `time_to_peak`. The
   inhibitory component shares its scale but is stretched by `inhibitory_time_constant_ratio`, so it peaks at

   .. math::

       \frac{(m_{inh} - 1) \kappa}{m - 1} \times \mathtt{time\_to\_peak} \approx 1.496 \times
       \mathtt{time\_to\_peak}

   Because the inhibitory component peaks later, the difference peaks *earlier* than the sustained channel and
   then crosses zero once into a negative lobe.

   .. rubric:: References

   .. [1] Kim, I., Kupers, E. R., Lerma-Usabiaga, G., & Grill-Spector, K. (2024). Characterizing spatiotemporal
       population receptive fields in human visual cortex with fMRI. *The Journal of Neuroscience*, 44(2),
       e0803232023. https://doi.org/10.1523/JNEUROSCI.0803-23.2023

   .. rubric:: Examples

   >>> import pandas as pd
   >>> impulse_model = TransientImpulse(duration=2.0, resolution=0.01)
   >>> params = pd.DataFrame({"time_to_peak": [0.05, 0.1, 0.2]})
   >>> resp = impulse_model(params)
   >>> print(resp.shape)  # (num_units, num_frames)
   (3, 200)


   .. py:method:: __call__(parameters: pandas.DataFrame, dtype: str | None = None) -> prfmodel.typing.Tensor

      Predict the impulse response.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units. Parameter values override default parameters.
      :type parameters: pandas.DataFrame
      :param dtype: The dtype of the prediction result. If `None` (the default), uses the dtype from
                    :func:`prfmodel.utils.get_dtype`.
      :type dtype: str, optional

      :returns: The predicted impulse response with shape `(num_units, num_frames)` and dtype `dtype`.
      :rtype: :data:`prfmodel.typing.Tensor`

      :raises ValueError: If `parameters` is missing one or more of :attr:`parameter_names`.



   .. py:method:: get_frames(dtype: str | None = None) -> prfmodel.typing.Tensor

      Build the time frames at which the impulse response function is evaluated.

      :param dtype: The dtype of the prediction result. If `None` (the default), uses the dtype from
                    :func:`prfmodel.utils.get_dtype`.
      :type dtype: str, optional

      :returns: Time frames of shape `(1, num_frames)` and dtype `dtype`. The first frame is at
                `offset + resolution / 2` and frames are spaced `resolution` apart.
      :rtype: :data:`prfmodel.typing.Tensor`

      .. rubric:: Notes

      Each frame is sampled at the centre of the interval it stands for, not at its leading edge: frame
      `i` covers `[offset + i * resolution, offset + (i + 1) * resolution)` and is evaluated at its
      midpoint, `offset + (i + 0.5) * resolution`. A sample represents the whole interval, and it keeps
      `t = 0` off the axis. At the defaults that is 32 samples centred at 0.5, 1.5, ..., 31.5 seconds.

      `duration` is an upper bound: the axis holds `num_frames = int(duration / resolution)` samples spaced
      exactly `resolution` apart, so it ends at the last whole sample at or below `duration` rather than at
      `duration` itself.
