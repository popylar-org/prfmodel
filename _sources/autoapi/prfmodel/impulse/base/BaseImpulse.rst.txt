prfmodel.impulse.base.BaseImpulse
=================================

.. py:class:: prfmodel.impulse.base.BaseImpulse(duration: float = 32.0, offset: float = 0.0, resolution: float = 1.0, norm: str | None = 'sum', default_parameters: dict[str, float] | str | None = None)



   Abstract base class for impulse models.

   An impulse model takes a set of parameters as input a predicts an impulse for time frames that are
   defined by an offset, duration, and resolution.

   :param duration: The duration of the impulse response (in seconds).
   :type duration: float, default=32.0
   :param offset: The offset of the impulse response (in seconds).
   :type offset: float, default=0.0
   :param resolution: The time resultion of the impulse response (in seconds), that is the number of points per second at which the
                      impulse response function is evaluated.
   :type resolution: float, default=1.0
   :param norm: The normalization of the response. Can be `"sum"` (default), `"mean"`, `"max"`, `"norm"`, or `None`.
                If `None`, no normalization is performed. See :doc:`Important details </important_details>`.
   :type norm: str, optional, default="sum"
   :param default_parameters: Dictionary with scalar default parameter values or name of default parameter set.
                              Dictionary keys must be valid parameter names. Default values are overridden by user-supplied parameters in
                              the :meth:`__call__` method.
   :type default_parameters: dict of float or str, optional

   .. rubric:: Notes

   This class cannot be instantiated on its own. It can only be used as a parent class to create custom response
   models. Subclasses must override the abstract :attr:`parameter_names` property and the :meth:`call`
   method.

   Each frame is sampled at its leading edge: frame `i` is the point sample `offset + i * resolution`.
   At the defaults that is 32 samples at t = 0, 1, ..., 31 seconds. See :doc:`Important details </important_details>`.

   `duration` is an upper bound: the time frames array holds `num_frames = int(duration / resolution)` samples
   spaced exactly `resolution` apart, so it ends at the last whole sample at or below `duration` rather than at
   `duration` itself.

   `duration` and `resolution` must be positive, checked once at construction. `offset` is
   unconstrained and may be negative. Note that `num_frames` is derived from `duration` alone,
   so a negative `offset` shifts the sampling window rather than widening it, and the far tail of the
   response is truncated by the same amount.


   .. py:method:: __call__(parameters: pandas.DataFrame, dtype: str | None = None) -> numpy.ndarray

      Compute the impulse response.

      This is the public entry point. It merges :attr:`default_parameters` into `parameters`, validates the
      result, converts it to tensors and delegates to :meth:`call`, then returns the result as a
      :class:`numpy.ndarray`. Subclasses implement :meth:`call`. Use :meth:`call` when a backend tensor is
      required.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units. Parameter values override default parameters.
      :type parameters: pandas.DataFrame
      :param dtype: The dtype of the prediction result. If `None` (the default), uses the dtype from
                    :func:`prfmodel.utils.get_dtype`.
      :type dtype: str, optional

      :returns: The predicted model response with shape `(num_units, num_frames)` and dtype `dtype`.
      :rtype: numpy.ndarray

      :raises ValueError: If `parameters` is missing one or more of :attr:`parameter_names`.



   .. py:method:: call(parameters: prfmodel.utils.TensorFrame) -> prfmodel.typing.Tensor
      :abstractmethod:


      Compute the impulse response from tensors.

      :param parameters: Model parameters as tensors, supporting the same column selection as a :class:`pandas.DataFrame`.
      :type parameters: TensorFrame

      :returns: The predicted model response with shape `(num_units, num_frames)` and dtype `dtype`.
      :rtype: Tensor

      .. rubric:: Notes

      Implementations must begin by calling :meth:`_join_default_parameters`, because a canonical model
      reaches its impulse submodel through this method rather than through :meth:`__call__`.

      Implementations must also be traceable by a backend compiler. See
      :meth:`~prfmodel.models.base.BaseTuning.call`.



   .. py:method:: check_parameter_names(parameters: pandas.DataFrame) -> None

      Check that required parameter names are supplied.

      If not already present, adds default parameter columns to ``parameters``.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame

      :raises ValueError: When a parameter name in the :attr:`parameters_names` attribute is not a column in ``parameters``.



   .. py:method:: check_parameter_values(parameters: pandas.DataFrame) -> None

      Check that the parameter values lie inside the domain the model is defined on.

      If not already present, adds default parameter columns to ``parameters``.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame

      :raises ValueError: When a parameter that must be ``> 0`` is zero or negative.



   .. py:method:: get_consumed_parameter_names(parameters: pandas.DataFrame) -> list[str]

      Return the parameter names the model reads from ``parameters``.

      A name covered by :attr:`default_parameters` is only read when the caller supplies a column for it;
      otherwise the default is merged in further down and the column would be absent here.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame

      :returns: Names of the parameters the model reads from ``parameters``.
      :rtype: list of str



   .. py:method:: get_frames(dtype: str | None = None) -> prfmodel.typing.Tensor

      Build the time frames at which the impulse response function is evaluated.

      :param dtype: The dtype of the prediction result. If `None` (the default), uses the dtype from
                    :func:`prfmodel.utils.get_dtype`.
      :type dtype: str, optional

      :returns: Time frames of shape `(1, num_frames)` and dtype `dtype`. The first frame is at
                `offset` and frames are spaced `resolution` apart.
      :rtype: :data:`prfmodel.typing.Tensor`

      .. rubric:: Notes

      The time frames are cached as a `numpy.ndarray` rather than as a backend tensor, and converted on every
      call.

      :type: float

   .. py:property:: resolution
      :type: float
