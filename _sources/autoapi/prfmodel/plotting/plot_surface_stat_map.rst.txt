prfmodel.plotting.plot_surface_stat_map
=======================================

.. py:function:: prfmodel.plotting.plot_surface_stat_map(mesh: nilearn.surface.PolyMesh, stat_map: numpy.ndarray, hemisphere: Literal['left', 'right', 'both'] = 'both', view: str | tuple[float, float] = (90, 270), vmin: float | None = None, vmax: float | None = None, cmap: str = 'inferno', cyclic: bool = False, title: str | None = None, **kwargs) -> tuple[matplotlib.figure.Figure, matplotlib.axes.Axes]

   Plot a statistic (e.g., a model parameter or score) on a cortical surface mesh.

   Wraps :func:`nilearn.plotting.plot_surf_stat_map` and enlarges the surface to fill the space next to the colorbar.

   :param mesh: Surface mesh to plot on (e.g., a flat or inflated surface).
   :type mesh: nilearn.surface.PolyMesh
   :param stat_map: Statistic for each vertex of the mesh with shape `(num_vertices,)`. If `hemi="both"`, the values of the left
                    hemisphere come first. `NaN` values are not shown.
   :type stat_map: numpy.ndarray
   :param hemisphere: Hemisphere(s) to plot.
   :type hemisphere: {"left", "right", "both"}, optional
   :param view: View of the surface passed to :func:`nilearn.plotting.plot_surf_stat_map`. The default `(90, 270)` (elevation,
                azimuth) shows a flat surface from above.
   :type view: str or tuple[float, float], optional
   :param vmin: Lower limit of the color scale.
   :type vmin: float or None, optional
   :param vmax: Upper limit of the color scale.
   :type vmax: float or None, optional
   :param cmap: Name of the colormap.
   :type cmap: str, optional
   :param cyclic: Whether the statistic is an angle in radians (e.g., pRF polar angle). If `True`, the color scale ranges
                  from :math:`-\pi` to :math:`\pi` with the cyclic colormap `"hsv"` so that both ends have the same color,
                  overriding `vmin`, `vmax`, and `cmap`.
   :type cyclic: bool, optional
   :param title: Title of the plot.
   :type title: str or None, optional
   :param \*\*kwargs: Keyword arguments passed to :func:`matplotlib.pyplot.subplots`. Defaults to `figsize=(8, 6)`.

   :returns: * **fig** (*matplotlib.figure.Figure*) -- Figure object.
             * **ax** (*matplotlib.axes.Axes*) -- Three-dimensional axes object.

   .. seealso::

      :py:obj:`prfmodel.utils.calculate_polar_angle`
          Polar angle of two-dimensional pRF centers.

      :py:obj:`prfmodel.utils.calculate_eccentricity`
          Eccentricity of two-dimensional pRF centers.
