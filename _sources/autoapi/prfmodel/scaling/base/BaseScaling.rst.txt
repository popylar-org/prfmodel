prfmodel.scaling.base.BaseScaling
=================================

.. py:class:: prfmodel.scaling.base.BaseScaling



   Abstract base class for scaling models.

   Scaling models modify a temporal input response (e.g., a neural response convolved with an impulse response).

   .. rubric:: Notes

   This class cannot be instantiated on its own. It can only be used as a parent class to create custom response
   models. Subclasses must override the abstract :attr:`parameter_names` property and the :meth:`call` method.
   Do not override :meth:`__call__`; it is the public facade that validates and converts before delegating to
   :meth:`call`, and returns a :class:`numpy.ndarray`.


   .. py:method:: __call__(inputs: prfmodel.typing.Tensor | numpy.ndarray, parameters: pandas.DataFrame, dtype: str | None = None) -> numpy.ndarray

      Make predictions with the scaling model.

      This is the public entry point; subclasses implement :meth:`call` instead. Use :meth:`call` when a
      backend tensor is required.

      :param inputs: Input tensor with temporal response and shape (num_units, num_frames).
      :type inputs: :data:`prfmodel.typing.Tensor` or numpy.ndarray
      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame
      :param dtype: The dtype of the prediction result. If `None` (the default), uses the dtype from
                    :func:`prfmodel.utils.get_dtype`.
      :type dtype: str, optional

      :returns: The predicted model response with shape `(num_units, num_frames)` and dtype `dtype`.
      :rtype: numpy.ndarray

      :raises ValueError: If `parameters` is missing one or more of :attr:`parameter_names`.



   .. py:method:: call(inputs: prfmodel.typing.Tensor, parameters: prfmodel.utils.TensorFrame) -> prfmodel.typing.Tensor
      :abstractmethod:


      Make predictions with the scaling model, from tensors.

      :param inputs: Input tensor with temporal response and shape (num_units, num_frames).
      :type inputs: :data:`prfmodel.typing.Tensor`
      :param parameters: Model parameters as tensors, supporting the same column selection as a :class:`pandas.DataFrame`.
      :type parameters: TensorFrame

      :returns: The predicted model response with shape `(num_units, num_frames)` and dtype `dtype`.
      :rtype: Tensor

      .. rubric:: Notes

      Implementations must be traceable by a backend compiler. See
      :meth:`~prfmodel.models.base.BasePopulationResponse.call`.



   .. py:method:: check_parameter_names(parameters: pandas.DataFrame) -> None

      Check that required parameter names are supplied.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame

      :raises ValueError: When a parameter name in the :attr:`parameter_names` attribute is not a column in ``parameters``.



   .. py:method:: check_parameter_values(parameters: pandas.DataFrame) -> None

      Check that the parameter values lie inside the domain the model is defined on.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame

      :raises ValueError: When a parameter that must be ``> 0`` is zero or negative.



   .. py:method:: get_consumed_parameter_names(parameters: pandas.DataFrame) -> list[str]

      Return the parameter names the model reads from ``parameters``.

      A name covered by :attr:`default_parameters` is only read when the caller supplies a column for it;
      otherwise the default is merged in further down and the column would be absent here.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame

      :returns: Names of the parameters the model reads from ``parameters``.
      :rtype: list of str



   .. py:property:: parameter_names
      :type: list[str]

      :abstractmethod:


      A list with names of parameters that are used by the model.
