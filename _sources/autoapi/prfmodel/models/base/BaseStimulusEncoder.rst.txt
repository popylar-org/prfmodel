prfmodel.models.base.BaseStimulusEncoder
========================================

.. py:class:: prfmodel.models.base.BaseStimulusEncoder



   Generic abstract base class for encoding model responses with a stimulus.

   A stimulus encoder takes a model response and stimulus as input and predicts a stimulus-encoded model response.

   .. rubric:: Notes

   Cannot be instantiated on its own.
   Can only be used as a parent class to create custom stimulus encoding models.
   Subclasses must override the abstract :attr:`parameter_names` property and the :meth:`call` method, and
   must be defined with a specific stimulus type and its matching tensor-holding type.
   See :mod:`~prfmodel.models.base` for details.

   Do not override :meth:`__call__`; it is the public facade that validates and converts before delegating
   to :meth:`call`, and returns a :class:`numpy.ndarray`.

   .. rubric:: Examples

   Reimplement a stimulus encoder for a :class:`~prfmodel.stimuli.PRFStimulus` that encodes the response
   by multiplying with the stimulus design and summing over the spatial dimensions.

   >>> import numpy as np
   >>> import pandas as pd
   >>> from prfmodel.examples import load_2d_prf_bar_stimulus
   >>> from prfmodel.stimuli import PRFStimulus, PRFStimulusTensors
   >>> from prfmodel.models.prf import encode_prf_response
   >>> class CustomPRFStimulusEncoder(BaseStimulusEncoder[PRFStimulus, PRFStimulusTensors]):
   ...     @property
   ...     def parameter_names(self):
   ...         return []
   ...     def call(self, stimulus, response, parameters):
   ...         return encode_prf_response(response, stimulus.design, dtype=parameters.dtype)
   >>> stimulus = load_2d_prf_bar_stimulus()
   >>> response = np.ones((3, 128, 128))  # dummy response of shape (num_units, num_y, num_x)
   >>> params = pd.DataFrame()
   >>> encoder = CustomPRFStimulusEncoder()
   >>> encoded = encoder(stimulus, response, params)
   >>> print(encoded.shape)  # (num_units, num_frames)
   (3, 170)


   .. py:method:: __call__(stimulus: S, response: prfmodel.typing.Tensor | numpy.ndarray, parameters: pandas.DataFrame, dtype: str | None = None) -> numpy.ndarray

      Encode a model response with a stimulus.

      This is the public entry point; subclasses implement :meth:`call` instead. Use :meth:`call` when a
      backend tensor is required.

      :param stimulus: Stimulus object.
      :type stimulus: Stimulus
      :param response: Model response.
      :type response: :data:`prfmodel.typing.Tensor` or numpy.ndarray
      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame
      :param dtype: The dtype of the prediction result. If `None` (the default), uses the dtype from
                    :func:`prfmodel.utils.get_dtype`.
      :type dtype: str, optional

      :returns: The stimulus encoded model response with shape `(num_units, ...)` dtype `dtype`. The number of units is
                the number of rows in :attr:`parameters`. The number and size of other axes depends on the stimulus and the
                response.
      :rtype: numpy.ndarray

      :raises ValueError: If `parameters` is missing one or more of :attr:`parameter_names`.



   .. py:method:: call(stimulus: T, response: prfmodel.typing.Tensor, parameters: prfmodel.utils.TensorFrame) -> prfmodel.typing.Tensor
      :abstractmethod:


      Encode a model response with a stimulus, from tensors.

      :param stimulus: The tensor-holding stimulus object, from :meth:`~prfmodel.stimuli.Stimulus.to_tensors`.
      :type stimulus: StimulusTensors
      :param response: Model response.
      :type response: :data:`prfmodel.typing.Tensor`
      :param parameters: Model parameters as tensors, supporting the same column selection as a :class:`pandas.DataFrame`.
      :type parameters: TensorFrame

      :returns: The stimulus encoded model response with shape `(num_units, ...)`.
      :rtype: :data:`prfmodel.typing.Tensor`

      .. rubric:: Notes

      Implementations must be traceable by a backend compiler. See
      :meth:`BaseTuning.call` for details.



   .. py:method:: check_parameter_names(parameters: pandas.DataFrame) -> None

      Check that required parameter names are supplied.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame

      :raises ValueError: When a parameter name in the :attr:`parameter_names` attribute is not a column in ``parameters``.



   .. py:method:: check_parameter_values(parameters: pandas.DataFrame) -> None

      Check that the parameter values lie inside the domain the model is defined on.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame

      :raises ValueError: When a parameter that must be ``> 0`` is zero or negative.



   .. py:method:: get_consumed_parameter_names(parameters: pandas.DataFrame) -> list[str]

      Return the parameter names the model reads from ``parameters``.

      A name covered by :attr:`default_parameters` is only read when the caller supplies a column for it;
      otherwise the default is merged in further down and the column would be absent here.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame

      :returns: Names of the parameters the model reads from ``parameters``.
      :rtype: list of str



   .. py:property:: parameter_names
      :type: list[str]

      :abstractmethod:


      A list with names of parameters that are used by the model.
