prfmodel.models.csf.CSFTuning
=============================

.. py:class:: prfmodel.models.csf.CSFTuning(width_l: float = 0.68, eps: float = 1e-10)



   Neural contrast sensitivity function tuning model.

   Predicts the tuning response to a contrast sensitivity function stimulus using
   an asymmetric log-parabolic CSF combined with a Naka-Rushton contrast response function.

   :param width_l: Curvature of the left branch of the asymmetric log-parabolic CSF (for spatial frequencies
                   below the peak). Not a fitted parameter; fixed at construction time.
   :type width_l: float, default=0.68
   :param eps: Minimum contrast and sensitivity value to ensure numerical and gradient stability.
   :type eps: float, default=1e-10

   .. rubric:: Notes

   The model has four fitted parameters:

   ``cs_peak``
       Peak contrast sensitivity.
   ``sf_peak``
       Peak spatial frequency (cycles/degree) at which sensitivity is maximal.
   ``width_r``
       Curvature of the right branch of the aLP CSF.
   ``slope_crf``
       Exponent :math:`q` of the Naka-Rushton CRF, controlling response steepness.

   .. seealso::

      :py:obj:`predict_contrast_sensitivity`
          Predict a contrast sensitivity function.

      :py:obj:`predict_contrast_response`
          Predict a contrast response based on a contrast sensitivity function.


   .. py:method:: __call__(stimulus: S, parameters: pandas.DataFrame, dtype: str | None = None) -> numpy.ndarray

      Predict the model response for a stimulus.

      This is the public entry point. It accepts the user-facing types, validates them, converts them to
      tensors and delegates the arithmetic to :meth:`call`, then returns the result as a
      :class:`numpy.ndarray`. Subclasses implement :meth:`call`, not this method. Use :meth:`call` when a
      backend tensor is required.

      :param stimulus: Stimulus object.
      :type stimulus: Stimulus
      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame
      :param dtype: The dtype of the prediction result. If `None` (the default), uses the dtype from
                    :func:`prfmodel.utils.get_dtype`.
      :type dtype: str, optional

      :returns: Model predictions of shape `(num_units, ...)` and dtype `dtype`. The number of units is the
                number of rows in `parameters`. The number and size of other axes depends on the stimulus.
      :rtype: numpy.ndarray

      :raises ValueError: If `parameters` is missing one or more of :attr:`parameter_names`.



   .. py:method:: call(stimulus: prfmodel.stimuli.CSFStimulusTensors, parameters: prfmodel.utils.TensorFrame) -> prfmodel.typing.Tensor

      Predict the tuning response for a CSF stimulus.

      :param stimulus: Tensor-holding contrast sensitivity function stimulus object,
                       from :meth:`~prfmodel.stimuli.CSFStimulus.to_tensors`.
      :type stimulus: CSFStimulusTensors
      :param parameters: Model parameters as tensors, supporting the same column selection as a :class:`pandas.DataFrame`.
      :type parameters: TensorFrame

      :returns: Model predictions of shape ``(num_voxels, num_frames)``.
                ``num_voxels`` is the number of rows in ``parameters`` and ``num_frames`` is the length of
                the stimulus sf and contrast arrays.
      :rtype: Tensor

   .. py:method:: get_consumed_parameter_names(parameters: pandas.DataFrame) -> list[str]

      Return the parameter names the model reads from ``parameters``.

      A name covered by :attr:`default_parameters` is only read when the caller supplies a column for it;

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame

      :returns: Names of the parameters the model reads from ``parameters``.
      :rtype: list of str
