prfmodel.models.csf.predict_contrast_response
=============================================

.. py:function:: prfmodel.models.csf.predict_contrast_response(contrast: prfmodel.typing.Tensor, sensitivity: prfmodel.typing.Tensor, slope_crf: prfmodel.typing.Tensor, dtype: str | None = None, eps: float = 1e-10) -> prfmodel.typing.Tensor

   Predict a neural contrast response from contrast sensitivity.

   Computes the response using a contrast sensitivity function combined with a Naka-Rushton
   contrast response function (CRF).

   :param contrast: Michelson contrast in percent (0 to 100) at each time frame, with shape ``(num_frames,)``.
   :type contrast: Tensor
   :param sensitivity: Contrast sensitivity for each voxel at each time frame, with shape ``(num_voxels, num_frames)``.
   :type sensitivity: Tensor
   :param slope_crf: Exponent :math:`q` of the Naka-Rushton CRF with shape ``(num_batches, 1)``.
   :type slope_crf: Tensor
   :param dtype: The dtype of the prediction result. If ``None`` (the default), uses the dtype from
                 :func:`prfmodel.utils.get_dtype`.
   :type dtype: str, optional
   :param eps: Minimum contrast sensitivity, which keeps the log of a zero sensitivity finite.
   :type eps: float, default=1e-10

   :returns: Predicted response with shape ``(num_batches, num_frames)`` and dtype ``dtype``.
   :rtype: Tensor

   .. rubric:: Notes

   The Naka-Rushton CRF combines contrast :math:`C` (in percent) with the contrast threshold :math:`Q = 100 / S(f)`
   (also in percent) derived from the CSF :math:`S(f)`:

   .. math::

       R(t) = \frac{C(t)^q}{C(t)^q + Q(t)^q}

   Contrast sensitivity is the reciprocal of the threshold contrast as a fraction, so the threshold in percent is
   :math:`100 / S(f)`. The response is half-maximal where the contrast equals the threshold, :math:`C(t) = Q(t)`.
   Frames with zero contrast (blank frames) have a response of exactly zero.

   For numerical stability, the CRF is evaluated in the log domain as the algebraically equivalent
   :math:`R(t) = \sigma(q \cdot (\log C(t) - \log Q(t)))`, where :math:`\sigma` is the logistic sigmoid. This avoids
   forming :math:`C^q` and :math:`Q^q`, which overflow for high contrasts, low sensitivities, or steep slopes.
