prfmodel.regressors.base.BaseRegressors
=======================================

.. py:class:: prfmodel.regressors.base.BaseRegressors



   Abstract base class for regressor models.

   A regressor model returns the additive contribution
   :math:`\sum_k \beta_k \, x_k(t)` of a set of regressors :math:`x_k(t)` to a model prediction. The per-unit
   weights :math:`\beta_k` come from the ``parameters`` argument and the design columns :math:`x_k(t)` come from
   the ``regressors`` data frame at call time.

   .. rubric:: Notes

   This class cannot be instantiated on its own. It can only be used as a parent class to create custom regressor
   models. Subclasses must override the abstract :meth:`call` method. Child classes should either assign the
   :attr:`_regressor_names` attribute during initialization or overwrite the :meth:`regressor_names` property and
   the :meth:`check_regressor_names` method.


   .. py:method:: __call__(regressors: pandas.DataFrame, parameters: pandas.DataFrame, dtype: str | None = None) -> numpy.ndarray

      Compute the additive regressor contribution.

      This is the public entry point; subclasses implement :meth:`call` instead. Use :meth:`call` when a
      backend tensor is required.

      :param regressors: Regressor design with shape `(num_frames, num_regressors)`. Must contain a column for each name in
                         :attr:`names`; extra columns are ignored.
      :type regressors: pandas.DataFrame
      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame
      :param dtype: The dtype of the prediction result. If `None` (the default), uses the dtype from
                    :func:`prfmodel.utils.get_dtype`.
      :type dtype: str, optional

      :returns: The predicted model response with shape `(num_units, num_frames)` and dtype `dtype`.
      :rtype: numpy.ndarray

      :raises ValueError: If `parameters` is missing one or more of :attr:`parameter_names`.



   .. py:method:: call(regressors: prfmodel.utils.TensorFrame, parameters: prfmodel.utils.TensorFrame) -> prfmodel.typing.Tensor
      :abstractmethod:


      Compute the additive regressor contribution from tensors.

      :param regressors: Regressor design columns as tensors, supporting the same column selection as a :class:`pandas.DataFrame`.
      :type regressors: TensorFrame or None, optional
      :param parameters: Model parameters as tensors, supporting the same column selection as a :class:`pandas.DataFrame`.
      :type parameters: TensorFrame

      :returns: The predicted model response with shape `(num_units, num_frames)` and dtype `dtype`.
      :rtype: Tensor

      .. rubric:: Notes

      Implementations must be traceable by a backend compiler. See
      :meth:`~prfmodel.models.base.BaseTuning.call`.



   .. py:method:: check_parameter_names(parameters: pandas.DataFrame) -> None

      Check that required parameter names are supplied.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame

      :raises ValueError: When a parameter name in the :attr:`parameter_names` attribute is not a column in ``parameters``.



   .. py:method:: check_parameter_values(parameters: pandas.DataFrame) -> None

      Check that the parameter values lie inside the domain the model is defined on.

      :param parameters: Dataframe with columns containing different model parameters and rows containing parameter values
                         for different units.
      :type parameters: pandas.DataFrame

      :raises ValueError: When a parameter that must be ``> 0`` is zero or negative.



   .. py:method:: check_regressor_names(regressors: pandas.DataFrame) -> None

      Check that required columns are supplied in the regressor design.

      :param regressors: Regressor design with shape `(num_frames, num_regressors)`. Must contain a column for each name in
                         :attr:`names`; extra columns are ignored.
      :type regressors: pandas.DataFrame

      :raises ValueError: When a column is missing in the regressor design.



   .. py:method:: get_consumed_parameter_names(parameters: pandas.DataFrame) -> list[str]

      :type parameters: pandas.DataFrame

      :returns: Names of the parameters this model and its submodels read from ``parameters``.
      :rtype: list of str
