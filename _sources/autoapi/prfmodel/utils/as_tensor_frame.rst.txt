prfmodel.utils.as_tensor_frame
==============================

.. py:function:: prfmodel.utils.as_tensor_frame(parameters: pandas.DataFrame | TensorFrame, dtype: str) -> TensorFrame

   Convert user-supplied parameters into the tensor-holding representation.

   This converts the parameters from a model's user-facing
   :meth:`__call__` to its tensor-only :meth:`call` implementation.

   :param parameters: Parameters to convert. A :class:`~prfmodel.utils.TensorFrame` is returned unchanged when it already
                      carries `dtype`, and rebuilt with `dtype` otherwise.
   :type parameters: pandas.DataFrame or TensorFrame
   :param dtype: The dtype that parameter tensors are converted to.
   :type dtype: str

   :returns: **parameters** -- Model parameters as tensors, supporting the same column selection as a :class:`pandas.DataFrame`.
   :rtype: TensorFrame

   .. rubric:: Examples

   >>> import pandas as pd
   >>> from prfmodel.utils import as_tensor_frame
   >>> params = as_tensor_frame(pd.DataFrame({"sigma": [1.0, 1.5]}), dtype="float32")
   >>> print(params.shape)
   (2, 1)
   >>> as_tensor_frame(params, dtype="float32") is params
   True
